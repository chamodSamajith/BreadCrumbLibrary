# BreadCrumb Library Prototype

full-stack library management prototype

---

## Tech Stack

### Backend
- ASP.NET Core Minimal API
- In-memory data storage

### Frontend
- React
- Axios
- Bootstrap

---

## Features

- View all books
- Search books by title
- Add new books
- Update book availability

---

## Project Structure

```txt
api/        -> ASP.NET Core backend
frontend/   -> React frontend
```

---

## Running the Backend

Navigate to the API project:

```bash
cd api
dotnet run
```

Backend runs on:

```txt
http://localhost:xxxx
```

---

## Running the Frontend

Navigate to the frontend project:

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```txt
http://localhost:3000
```

---

## Notes

- in memory storage was used.
- the provided external Swagger API  is, so this was completed using a mocked APIs.
